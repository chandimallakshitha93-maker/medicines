# Hospital Locator – how to update

The page reads **data.csv**. Edit that file and the page updates within a few minutes.

Columns: Item, Area, Place, Code, Category, Note, PaperColour, InventoryNo

* **On a phone or computer:** open data.csv on GitHub → pencil (Edit) → add or change a line → Commit changes.
* **With Excel:** download data.csv, edit, *Save As → CSV UTF-8*, then on GitHub open the `locator` folder → Add file → Upload files → drop data.csv → Commit changes.

Keep the first (header) row unchanged. One item per row.
